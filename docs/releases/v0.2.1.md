# PotatoCs / Odysseus Desktop v0.2.1 — Stats for Nerds

## Summary

PotatoCs is a local-first AI desktop project for ordinary computers. The
public project currently ships its Windows app as Odysseus Desktop v0.2.1.

This patch makes local AI behavior easier to inspect. It adds a per-answer
operation trace while preserving the existing local-first architecture and
keeping sensitive prompt, response, and document content out of the trace.

## What changed

- Added **Stats for Nerds / Operation Trace** under assistant messages.
- Persisted compact trace metadata with each answer in the profile-local
  SQLite database.
- Exposed timing, model routing, pipeline state, token, retrieval, and warning
  metadata in the chat UI.
- Kept trace availability explicit when an underlying model or runtime does
  not provide detailed metadata.

## Stats for Nerds / Operation Trace

Each trace can show:

- Total and stage-level timing.
- Selected chat, embedding, OCR, and vision models or backends.
- Pipeline and RAG state.
- Input and output token counts when the runtime reports them.
- Source and retrieval identifiers.
- Warnings, fallback paths, and model-trace availability.

An operation trace is diagnostic metadata, not a guarantee that an answer is
correct. It is meant to make routing, evidence use, and performance easier to
audit on local hardware.

## Privacy protections

The v0.2.1 trace deliberately avoids storing:

- Raw prompts.
- Raw model responses.
- Source paths.
- Base64 images.
- Full OCR text.
- Full RAG context.
- Retrieved chunk text.
- Full model thinking text.

Trace metadata stays in the local SQLite profile alongside the conversation.

The installer is published as a GitHub Release asset with a separate SHA-256
checksum file. The app remains internally named Odysseus Desktop in v0.2.1.

## Known limitations

- The installer is large because it bundles the embedded Python runtime and
  Florence resources.
- Local vision-language models can be slow on modest hardware.
- The app is still named Odysseus Desktop internally for v0.2.1.
- Operation traces expose execution metadata, not full hidden model reasoning
  or proof of answer correctness.
- Small local models can still hallucinate, miss evidence, or over-abstain.
