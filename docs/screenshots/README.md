# Screenshots

This folder is reserved for clean screenshots from packaged Windows builds.

Recommended captures:

- `chat-rag-sources.png` - chat with RAG enabled and retrieved source chips.
- `documents-import.png` - document import, index status, OCR status, and test retrieval.
- `legacy-import-report.png` - non-destructive import report.
- `installer-start-menu.png` - app launched from the Windows Start Menu.

Screenshots should show the installed app, not the Vite/Tauri development build.
